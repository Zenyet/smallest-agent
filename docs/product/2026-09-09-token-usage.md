# 对话用量显示

已接入内置 Agent 的 Chat Completions 和 Responses SDK 用量。流式兼容接口主动请求 usage 尾帧。每次完成的模型调用随会话保存，回复下方汇总本轮主 Agent 输入、输出、总 Token、服务端缓存读取、推理量和本地缓存次数；工具循环多次请求累加。用量元数据不参与缓存键和模型提示。

输入框上方显示最近请求实际输入 Token，以及当前文字草稿粗略估算。最近请求不是当前草稿发送后的总上下文；没有可靠的模型窗口容量，因此不展示虚构的占用百分比。草稿估算不包括附件。

本地缓存命中记录零新增 Token，保留原请求上下文量供参考。服务端缓存读取和推理分别是输入、输出的子集，不重复相加；服务端字段缺失时显示未上报。中断时保留此前已完成调用的统计。

统计不是账单：未包含摘要、记忆抽取、答案核查、子 Agent、失败或中断且没有返回 usage 的调用。外部 CLI 暂未接入用量。旧会话无法追补；记录随会话历史保存，历史压缩或编辑截断后不作为永久用量台账。

验证：真实 SDK + 假 HTTP 响应检查非流式/流式协议映射、usage 请求开关；测试未知值、本地缓存去重、历史回放、多轮工具聚合及会话隔离。
