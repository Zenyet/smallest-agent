# 设置改版交付说明

日期：2026-09-09。主交付端为 Electron。沿用现有深色设计体系、内嵌设置页面和单列侧栏。

## 已实现

- 五类导航：模型连接、Agent 与工具、记忆与资料、对话偏好、高级与诊断。常规界面使用自然语言标签，环境变量字段折叠展示。
- 服务列表按项展开，支持添加现有目录中的服务、兼容端点、密码显示 / 隐藏、明确保存与放弃修改。
- 普通开关按字段依次保存；数字在失焦 / Enter 或返回时提交。多个字段和连续切换不会提交整份旧表单。
- 凭据和成组配置显式保存。清空通过经过校验的 unset 操作移除本机值，页面说明环境变量回退语义。
- 待生效状态由主进程的启动配置快照计算。保存完成、切页或重新进入设置后仍会显示；恢复原值后解除提示。
- 真实连接验证接口使用该服务的首个配置模型，发送一次最小文本验证任务，不带历史或工具。显示测试模型、时间、成功或经过脱敏的失败信息；超时中止请求，配置变更后旧结果失效。
- 导入先检测和预览，确认后只保存目标服务的 API Key，不改变当前会话的厂商或模型。
- 记忆支持全局 / 当前项目筛选、显式编辑保存、删除和撤销；编辑按钮保持可见。撤销不会覆盖当前已存在的同名记忆，过期删除会提示刷新。
- 记忆读取失败和空列表分别展示，支持重试。常规 Agent 检索仍保留原来的容错读取行为。
- 笔记目录使用原生选择器，展示当前生效目录和按需初始化状态；高级索引配置折叠。
- 返回时等待普通设置保存；存在凭据等表单草稿时提供保存并返回 / 放弃 / 继续编辑。打开设置期间保留对话组件，返回后未发送的文字、附件和原会话仍在。

## 现阶段边界

- 笔记目录、嵌入模型、下载镜像变更仍需重启应用，沿用正在运行任务和待审批操作的重启守卫。手动刷新与目录热切换留待后续，界面没有假刷新按钮。
- 外部 CLI 显示启用状态和配置入口，不把“已启用”当作已安装、已登录或握手成功。
- 连接验证仅证明本次测试模型的文本请求可用，不能代表图片、PDF、工具调用或所有模型均可用。
- 撤销记录保留在本次主进程中，最多 50 条；重启后不可撤销此前的删除。后端检查当前记录以避免覆盖同名新内容；没有引入跨 CLI 进程的文件事务锁。
- 设置页本次打开期间保留分区草稿；未提交草稿不承诺在应用退出或崩溃后恢复。

## 验证

- TypeScript 类型检查通过。
- 全量 86 个测试文件、1,090 项测试通过。旧版布局断言已调整为新布局及保存流程的行为测试。
- Electron 主进程、预加载与渲染器构建通过。
- 使用演示数据检查实际渲染界面的连接页、记忆页、820px 最小桌面窗口、保存返回及对话草稿保留；浏览器未报告前端脚本错误。
- 模型验证通过注入的模拟调用覆盖指定服务、无密钥本地端点、错误脱敏与超时；本轮没有使用真实用户凭据调用外部模型。

运行 `npm run dev:electron` 后，点击侧栏「设置」即可使用。
